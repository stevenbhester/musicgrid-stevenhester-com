Why Spotify sign-in needs approval

Spotify now lets small apps like MusicGrid connect only a handful of Spotify accounts, and Steven has to add each one by hand. If yours isn't on the list, Spotify won't let you connect. Ask Steven to add you, or use "Pick any artists", which works for everyone.
