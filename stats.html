    Your player code

    Leaderboards know you by a secret code saved in this browser, not by the name you type. That keeps two players called Sam apart, and nobody can claim your scores just by using your name. The code is never shown to other players.

    Play on another phone or computer too? Open this browser's link there, or make up your own code and type it on each device. Either way they count as one player: one all-time total and one set of stats. If you finished a grid on both, the higher score counts.

    Make up your own, like a password you'll remember (at least 8 characters), or paste the code from another device. Capitals and extra spaces don't matter.

    Keep your code and link private, and pick a code nobody else would type. Anyone who uses the same code plays as you.

    Finished games are saved with your player code, so devices you link share stats. Clearing your browser data gives this browser a new code, so type your code or open your link again to get your stats back.
